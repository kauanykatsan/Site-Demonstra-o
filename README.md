# Herança Digital
Plataforma segura e criptografada para organizar seus bens digitais em vida e garantir que seus herdeiros tenham acesso após o falecimento.

## Sobre o projeto
Senhas, investimentos, criptoativos, documentos e memórias — tudo em um cofre digital protegido com criptografia AES-256, com liberação controlada por certidão de óbito e validação dupla.

## Tecnologias
- HTML5 / CSS3
- JavaScript
