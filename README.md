#  Herança Digital🔐

Uma plataforma segura e criptografada para organizar ativos digitais em vida e garantir que pessoas autorizadas tenham acesso a eles após o falecimento.

# Sobre o Projeto

O Herança Digital foi desenvolvido durante o TechStars Startup Weekend Chapecó com o objetivo de oferecer um cofre digital para armazenamento de informações importantes, como:

Senhas e contas digitais
Investimentos e criptoativos
Documentos importantes
Fotos, vídeos e memórias digitais

As informações são protegidas por criptografia AES-256 e contam com um processo de liberação controlada, incluindo validação por documentação e mecanismos de segurança adicionais.
